## Instrucciones para ejecutarlo en tu ambiente local

Recomiendo utilizar [Visual Studio Code](https://code.visualstudio.com/download) para levantar este proyecto debes tener instalado [BUN](https://bun.sh/).

> Nota: Estos pasos son los que yo recomendado, si prefieres otra forma, eres libre. Recomiendo esto, porque así puedes modificarlo si gustas.

### Paso 1

Descarga o clona el proyecto desde [mi Github](https://github.com/javiertdev/luiscortes.cl).

```bash
git clone git@github.com:javiertdev/luiscortes.cl.git
```

### Paso 2

Abre el proyecto con VSCode, desde donde lo descargaste o clonaste.

```bash
code ruta/a/luiscortes.cl
```

### Paso 3

En una terminal del VSCode, instala las dependencias usando BUN.

```bash
bun install
```

### Paso 4

Una vez instaladas todas las dependencias con éxito, ¡ya puedes levantar el proyecto!


```bash
bun run dev
```
